Premium Dark UI Rules
Visual Identity

Target aesthetic:

Premium SaaS
Modern
Smooth
Professional
Minimal
Dark theme first

Inspirations:

Linear
GitHub Dark
Stripe Dashboard
Vercel

Avoid:

Bootstrap-like appearance
Flat unfinished interfaces
Generic admin panel look
Pure black backgrounds
Excessive gradients
Excessive animations

Interaction Feedback

Every interactive element must visibly react.

Buttons:

Slight brightness increase on hover
Soft blue outline on hover
Scale 1.01–1.02
Smooth transition

Cards:

Slight lift
Slight shadow increase
Border becomes slightly brighter

Links:

Color transition
Underline animation or opacity transition

Table Rows:

Background highlight on hover
Smooth transition

Icons:

Subtle color shift on hover

No interactive element should appear static.

Hover Effects

Hover effects must be subtle.

Use:

Border glow
Soft blue shadow
Small elevation
Small brightness increase

Avoid:

Large scaling
Strong glows
Flashy effects
Aggressive color changes

Users should feel feedback without consciously noticing it.

Shadows

Use layered shadows.

Cards should appear slightly elevated from the background.

Example style:

Soft shadow
Low opacity
Large blur radius

Avoid harsh shadows.

Borders

Use borders everywhere.

Requirements:

Thin
Subtle
Consistent

Borders should separate elements without becoming visually dominant.

Buttons

Primary Button:

Blue background
White text
Hover brightness increase
Soft blue glow
Smooth transition

Secondary Button:

Transparent background
Visible border
Hover fill effect

Danger Button:

Red accent
Confirmation required

Every button must have:

Default state
Hover state
Active state
Disabled state
Loading state
Focus state
Forms

Inputs must feel premium.

Requirements:

Default:

Dark surface
Subtle border

Hover:

Slight border brightness increase

Focus:

Blue border
Blue focus ring
Smooth animation

Error:

Red border
Clear message

Success:

Green indicator

Never allow inputs to feel invisible.

Dashboard Layout

Cards should be aligned to a consistent grid.

Metrics:

Total spent
Monthly budget
Remaining budget
Category spending

Charts must have breathing room.

Avoid crowded layouts.

Animations

Duration:

150ms–250ms

Easing:

ease-out

Allowed:

Fade
Scale
Slide
Elevation

Avoid:

Bounce
Elastic
Long animations

The interface should feel fast.

Loading States

Always include:

Skeleton loaders
Button loading states
Chart loading states
Async operation feedback

Never show blank containers.

Empty States

Every empty state must contain:

Icon
Message
Explanation
Call to action

The application must never appear broken.

Toast Notifications

Success:

Green accent

Error:

Red accent

Warning:

Yellow accent

Requirements:

Slide in smoothly
Auto dismiss
Manual close option
Mobile Experience

The mobile version must feel intentionally designed.

Do not simply stack desktop elements.

Requirements:

Large touch targets
Comfortable spacing
Sticky actions when useful
Responsive charts
Responsive tables
Quality Check

Before completing any page:

Does every interactive element have hover feedback?
Does every form field have focus feedback?
Does every action have loading feedback?
Does every state exist? (loading, success, error, empty)
Does the interface feel premium?
Would this look acceptable in a paid SaaS product?

If not, continue refining.
